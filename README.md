# Hi there, I'm Erfan Ghasemi 👋

## Senior Data Scientist & Biostatistician | Edmonton, Canada 🇨🇦

I build **production data science systems** — models that get deployed, monitored, and used to make decisions. Currently leading a data science team building real-time detection systems; previously built analytics and ML platforms in pharma/CRO and national-scale health data environments.

My edge is depth on the statistics side: I've spent a decade working with messy, high-stakes, real-world data — claims databases, clinical registries, sensor streams, trials — where getting the inference *right* matters as much as getting the model to ship.

⚙️ Production ML & MLOps · 📊 Causal inference on observational data · 🧬 Multi-omics & biomarker discovery · 🤖 LLM/RAG systems

**Modelling**
Predictive modelling · deep learning (CNNs, transformers) · LLMs and RAG · time series forecasting · survival analysis · longitudinal & mixed-effects models · Bayesian inference
